# Precision Medicine: A Data Science Approach to Diabetes Classification
## Project Description
#### This application created using python code and the streamlit library gives users the opportunity to explore the Diabetes Health Indicators dataset. The applicaiont contains an exploratory data analysis of the data and the implementation of three machine learning models from Sci-kit learn: K-Nearest Neighbors Classifier, Random Forest Classifier, and MLP Classifier.
## Challenges
#### One challenge of the project was models having lengthy run time, more specifically the runtime for MLP Classifier. In the future the application may utlize another neural network that can train at a faster speed, or swap to GPU processing.
